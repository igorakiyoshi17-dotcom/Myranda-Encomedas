IMPORTANTE
O arquivo produtos.json que acompanha este ZIP AINDA É O MODELO COM 12 PEÇAS.
O catálogo completo só aparece quando o importador rodar com sucesso no GitHub.
O ambiente em que este pacote foi feito não conseguiu baixar diretamente o site
original para testar a extração real; o script foi testado com páginas de exemplo.
Se o fornecedor mudar o HTML, bloquear a requisição ou mudar as fotos, o
importador mostrará erro e preservará o catálogo anterior. Não declare o
catálogo completo antes de confirmar o resultado da execução.

PASSO 1 — ATUALIZAR O REPOSITÓRIO
1. Baixe o ZIP e clique com botão direito > Extrair tudo.
2. Entre no repositório GitHub que você já criou: Myranda-Encomendas.
3. Clique em Add file > Upload files.
4. Arraste PARA A PÁGINA de upload o conteúdo EXTRAÍDO, incluindo as pastas:
     index.html
     produtos.json
     produtos_modelo.csv
     LEIA-ME.txt
     scripts/
     .github/
   Preserve a estrutura das pastas. Não envie o ZIP diretamente.
5. Clique em Commit changes (branch main).

PASSO 2 — IMPORTAR OS PRODUTOS DO FORNECEDOR
1. No GitHub, abra a aba Actions.
2. Encontre "Atualizar catálogo de encomendas (Mya)".
3. Clique em Run workflow > main > Run workflow.
4. Aguarde a execução terminar. Uma marca VERDE significa sucesso.
5. O importador faz um commit automático de produtos.json atualizado.
6. A Vercel normalmente publica a alteração sozinha. Reabra o catálogo e
   atualize a página com Ctrl+F5 após alguns minutos.

SE DER ERRO
Abra a execução vermelha em Actions > importar > etapa que falhou,
e envie um print do erro. Não precisa alterar nada do site principal.
O script verifica se foram obtidos pelo menos 100 produtos com 70% das fotos;
se a verificação falhar, NÃO sobrescreve produtos.json.

O QUE NÃO É ATUALIZADO
- Preços (nunca são importados nem exibidos).
- Estoque real e disponibilidade: a cliente solicita e você confirma.
- Pedidos, pagamentos ou banco de dados do site principal.
- Fotos em servidor próprio: são links para fotos públicas do fornecedor.

USO DAS IMAGENS
Os arquivos presumem autorização de uso comercial dada pela fornecedora,
conforme informado pela titular da Myranda. Se a autorização for revogada
ou houver restrições, interrompa a importação e substitua as imagens.
